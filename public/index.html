Kenapa Rex API

Cepat dan bisa ditebak

Response di-cache, media besar dialirkan lewat proxy bertanda tangan, dan batas waktu ditegakkan per endpoint.

Dijaga serius

API key disimpan terenkripsi, URL dari luar disaring anti-SSRF, dan setiap tindakan admin tercatat.

Dokumentasi yang hidup

Tiap endpoint punya playground. Isi parameter, kirim, lalu salin kodenya untuk cURL, Node, atau Python.
