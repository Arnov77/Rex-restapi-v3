How it works

Get started in three steps

No credit card, no framework, no boilerplate — from signup to first response in under five minutes.

  1. Grab your key

    Create a free account and copy your personal rex_ API key from the dashboard. Anonymous requests work too, at 15/day per IP.

    1. Sign up at /dashboard
2. Copy your key under API Keys

  2. Make your first request

    Attach the key as a Bearer token and call any endpoint. Responses are JSON with success, data, and ms.

    curl -H "Authorization: Bearer rex_…" \
  https://rexapi.my.id/api/ai/imagegen?q=cat

  3. Build & scale

    Wire it into your Discord, WhatsApp or Telegram bot, track usage in the dashboard, and upgrade when you outgrow 150 requests/day.

    const res = await fetch(
  "/api/downloader/youtube?q=URL", {
  headers: { "Authorization": "Bearer rex_…" }
});

FAQ

Frequently asked questions

Is Rex API free to use?
Yes. The Anonymous tier gives you 15 requests per day per IP with no sign-up, and the Registered tier gives 150 requests per day with a personal API key — both completely free.
How do I get an API key for my bot or app?
Create a free account at the dashboard, then copy your personal rex_ API key from the API Keys tab. Include it in the Authorization header as a Bearer token with every request: Authorization: Bearer rex_….
What endpoints does Rex API provide?
Rex API provides over 80 endpoints grouped into media downloaders (YouTube, TikTok, Instagram, Twitter/X), AI tools (chat, image generation, transcription), image makers, web utilities (screenshots, OCR, QR codes), search, games, and shortlinks with click tracking.
Can I use Rex API with Discord, WhatsApp or Telegram bots?
Yes — that is exactly what it was built for. The JSON response shape (success, data, ms) maps cleanly onto Discord.js, Telegraf, and other bot frameworks, and most downloaders return direct media URLs you can forward immediately.
What happens when I hit my daily limit?
Requests beyond the daily quota receive a 429 response with a JSON body explaining the limit. Anonymous limits reset per IP at midnight UTC; registered limits reset per account. Your dashboard shows live usage so you can plan ahead.
Is my API key secure?
Keys are transmitted only over HTTPS and validated as signed JWT tokens server-side — they cannot be forged or tampered with. You can rotate or revoke keys at any time from the dashboard without changing your account.
