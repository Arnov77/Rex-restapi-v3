Dokumen ini menjelaskan data yang Rex API kumpulkan, alasan penggunaannya, pihak yang dapat menerima atau memproses data tersebut, serta cara kamu dapat meminta penghapusannya.

Data yang kami simpan

Saat kamu membuat akun

Data Tujuan
Alamat email Digunakan sebagai identitas akun dan sebagai sarana untuk menghubungimu terkait akun atau layanan.
Username Digunakan sebagai identitas yang ditampilkan di dashboard.
Kata sandi Kata sandi tidak disimpan dalam bentuk teks asli dan tidak dapat dilihat kembali oleh kami.
Nama dari Google atau GitHub Disimpan jika kamu memilih masuk menggunakan Google atau GitHub, dan dapat digunakan sebagai nama tampilan di dashboard.
ID akun penyedia login Digunakan untuk mengenali akunmu saat masuk kembali melalui Google atau GitHub.

Saat kamu menggunakan API

  • API key — disimpan dalam bentuk terenkripsi. Kunci asli hanya ditampilkan kepada pemilik akun melalui fitur yang tersedia.
  • Penghitung pemakaian harian — mencatat jumlah request yang dilakukan setiap hari untuk menghitung dan menerapkan batas penggunaan.
  • Waktu login terakhir — digunakan untuk informasi aktivitas akun.
  • Catatan tindakan admin — perubahan tertentu yang dilakukan pengelola terhadap akun dapat dicatat untuk keperluan administrasi dan keamanan.

Yang tidak kami simpan secara permanen: isi request dan response dari endpoint yang kamu gunakan tidak disimpan ke basis data aplikasi setelah pemrosesan selesai.

Beberapa endpoint dapat menggunakan file sementara. File hasil unduhan, unggahan, atau pemrosesan gambar dapat disimpan sementara di server hingga satu jam sebelum dihapus secara otomatis.

Pihak ketiga

Untuk menyediakan Rex API, kami menggunakan beberapa layanan pihak ketiga. Layanan tersebut dapat menerima atau memproses data tertentu sesuai dengan fungsi yang digunakan.

Layanan Data yang dapat diproses
Supabase Digunakan untuk autentikasi dan penyimpanan data aplikasi, termasuk data akun dan informasi terkait layanan.
Google Jika kamu memilih masuk dengan Google, Google memproses proses autentikasi dan memberikan informasi dasar akun yang kamu izinkan, seperti alamat email, nama, dan identitas akun.
GitHub Jika kamu memilih masuk dengan GitHub, GitHub memproses proses autentikasi dan memberikan informasi akun yang diperlukan untuk menghubungkan akun GitHub dengan Rex API.
Cloudflare Digunakan untuk meneruskan dan melindungi lalu lintas menuju layanan kami. Cloudflare dapat memproses alamat IP dan metadata permintaan yang melewati jaringannya.
Penyedia model AI Teks yang dikirim ke endpoint AI dapat diteruskan ke penyedia model pihak ketiga untuk diproses. Hindari mengirimkan informasi sensitif atau rahasia melalui endpoint tersebut.
Penyedia pemrosesan gambar Gambar yang dikirim ke endpoint tertentu, seperti upscaler atau pemrosesan gambar lainnya, dapat diteruskan ke layanan pihak ketiga untuk diproses.

Kami tidak menjual data pribadi pengguna dan tidak menggunakan pelacak iklan untuk menjual atau membagikan profil pengguna kepada pengiklan.

Berapa lama data disimpan

Saat ini, kami belum menerapkan jadwal penghapusan otomatis untuk seluruh data akun. Data akun disimpan selama akun tetap aktif di Rex API.

Jika kamu menghapus akun melalui dashboard, data utama yang terkait dengan akun tersebut, termasuk API key dan data penggunaan akun, akan dihapus dari sistem kami.

File sementara hasil unduhan, unggahan, atau pemrosesan gambar merupakan pengecualian dan dapat disimpan hingga satu jam sebelum dihapus secara otomatis.

Menghapus akun

Kamu dapat menghapus akun secara langsung melalui dashboard. Buka halaman Profil, lalu pilih Hapus akun.

Sebelum akun dihapus, kamu akan diminta memasukkan kata sandi untuk mengonfirmasi bahwa permintaan penghapusan dilakukan oleh pemilik akun.

Setelah penghapusan dikonfirmasi, akun beserta API key dan data penggunaan yang terkait akan dihapus dari sistem kami. Penghapusan akun tidak dapat dibatalkan.

Keamanan

  • Kata sandi tidak disimpan dalam bentuk teks asli.
  • API key disimpan dalam bentuk terenkripsi.
  • Data dikirim melalui koneksi HTTPS.

Kami menerapkan langkah-langkah yang wajar untuk melindungi data, tetapi tidak ada sistem yang dapat menjamin keamanan sepenuhnya. Jika terjadi insiden keamanan yang berdampak pada data pengguna, kami akan memberikan pemberitahuan melalui sarana yang tersedia apabila diperlukan.

Anak-anak

Rex API tidak ditujukan untuk anak berusia di bawah 13 tahun. Kami tidak dengan sengaja mengumpulkan data pribadi dari anak di bawah usia tersebut.

Perubahan kebijakan

Jika kebijakan ini diperbarui, tanggal berlaku di bagian atas halaman akan ikut diperbarui. Untuk perubahan yang berdampak signifikan terhadap penggunaan data pribadi, pemberitahuan dapat diberikan melalui email atau melalui layanan Rex API.
