Ketentuan Layanan

Berlaku sejak 20 September 2026

Dengan menggunakan Rex API, kamu dianggap telah membaca dan menyetujui ketentuan di bawah ini. Kami berusaha menyajikannya dengan bahasa yang jelas dan ringkas.

Tentang layanan

Rex API menyediakan berbagai endpoint untuk mengunduh media, memproses gambar, menggunakan model AI, dan menjalankan berbagai utilitas web. Layanan ini dioperasikan secara independen oleh individu, bukan perusahaan.

Akun dan API key

  • Setiap pengguna hanya diperbolehkan memiliki satu akun. Membuat beberapa akun untuk memperoleh kuota tambahan tidak diperbolehkan.
  • Kamu bertanggung jawab menjaga keamanan API key milikmu. Jangan membagikannya atau menempatkannya di kode, repositori, atau aplikasi publik yang dapat diakses orang lain.
  • Jika API key bocor atau diduga telah diketahui pihak lain, segera gunakan fitur Regenerate melalui dashboard untuk membuat key baru.

Kuota dan batas penggunaan

Penggunaan tanpa API key dapat dibatasi berdasarkan alamat IP. Untuk penggunaan dengan API key, batas harian mengikuti kuota yang ditampilkan di dashboard.

Batas penggunaan dapat disesuaikan sewaktu-waktu berdasarkan kapasitas, kondisi server, dan kebutuhan operasional layanan.

Penggunaan yang tidak diperbolehkan

  • Melanggar hak cipta atau hak pihak lain. Kamu bertanggung jawab memastikan bahwa konten yang diakses, diunduh, atau diproses melalui Rex API memang boleh kamu gunakan dan tidak melanggar hak pihak lain.
  • Menjual ulang akses Rex API. Menawarkan kembali akses Rex API sebagai layanan berbayar milikmu sendiri tanpa izin tidak diperbolehkan.
  • Melewati batas penggunaan. Termasuk menggunakan banyak akun, pergantian alamat IP, proxy, VPN, atau metode lain dengan tujuan menghindari kuota atau pembatasan layanan.
  • Mengganggu layanan. Mengirim permintaan otomatis atau lalu lintas dalam jumlah tidak wajar yang dapat mengganggu kestabilan layanan atau pengguna lain tidak diperbolehkan.
  • Melanggar hukum. Rex API tidak boleh digunakan untuk aktivitas yang melanggar hukum yang berlaku.
  • Menyalahgunakan data pribadi. Rex API tidak boleh digunakan untuk mengumpulkan atau memproses data pribadi orang lain dengan tujuan pelecehan, penguntitan, penipuan, atau bentuk penyalahgunaan lainnya.

Jika ketentuan ini dilanggar, kami dapat membatasi akses, menonaktifkan API key, atau menonaktifkan akun. Dalam kasus penyalahgunaan serius atau risiko terhadap keamanan layanan, tindakan dapat dilakukan tanpa pemberitahuan sebelumnya.

Konten yang kamu kirim

Kamu bertanggung jawab atas konten yang dikirim melalui Rex API. Kami tidak meninjau setiap konten secara manual sebelum diproses.

Isi request dan response tidak disimpan secara permanen di basis data aplikasi setelah pemrosesan selesai. Beberapa endpoint dapat menggunakan file sementara yang disimpan hingga satu jam sebelum dihapus secara otomatis, sebagaimana dijelaskan dalam Kebijakan Privasi.

Data yang dikirim ke endpoint tertentu dapat diteruskan ke layanan pihak ketiga yang diperlukan untuk memproses permintaan. Misalnya, teks yang dikirim ke endpoint AI dapat diteruskan ke penyedia model AI, dan gambar yang dikirim ke endpoint pemrosesan gambar dapat diteruskan ke layanan pemrosesan terkait.

Hindari mengirimkan informasi sensitif, rahasia, atau data yang tidak seharusnya dibagikan melalui layanan ini.

Ketergantungan pada layanan pihak ketiga

Beberapa fitur Rex API bergantung pada situs, API, model AI, atau layanan pihak ketiga yang berada di luar kendali kami.

Jika layanan pihak ketiga mengubah sistem, membatasi akses, mengalami gangguan, atau menghentikan layanan, fitur Rex API yang bergantung padanya dapat ikut terganggu atau berhenti berfungsi.

Tanpa jaminan

Rex API disediakan sebagaimana adanya. Kami tidak menjamin bahwa layanan akan selalu tersedia, bebas dari gangguan, atau menghasilkan data yang selalu akurat.

Layanan dapat mengalami perubahan, gangguan, pemeliharaan, atau penghentian sementara maupun permanen. Kami juga tidak menjamin setiap endpoint akan tetap tersedia atau berfungsi dengan cara yang sama selamanya.

Rex API tidak dirancang untuk penggunaan yang bersifat kritis atau sebagai satu-satunya sistem yang diandalkan untuk layanan yang membutuhkan ketersediaan atau keakuratan tinggi.

Batas tanggung jawab

Sejauh diizinkan oleh hukum yang berlaku, kami tidak bertanggung jawab atas kerugian yang timbul akibat penggunaan, gangguan, perubahan, atau ketidaktersediaan Rex API, termasuk kehilangan data, kehilangan akses, atau gangguan pada aplikasi yang menggunakan layanan ini.

Kamu bertanggung jawab atas cara Rex API digunakan di aplikasi, bot, situs web, atau sistem lain yang kamu bangun.

Perubahan layanan

Kami dapat menambah, mengubah, membatasi, atau menghapus endpoint dan fitur tertentu jika diperlukan untuk menjaga layanan, memperbaiki sistem, menyesuaikan kapasitas, atau mengikuti perubahan dari layanan pihak ketiga.

Perubahan ketentuan

Ketentuan ini dapat diperbarui dari waktu ke waktu. Tanggal berlaku di bagian atas halaman menunjukkan versi terbaru.

Perubahan yang berdampak signifikan dapat kami informasikan melalui Rex API, dashboard, atau email jika diperlukan.
